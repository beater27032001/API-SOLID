# Pasta `lib/`

## Objetivo

Esta pasta contém bibliotecas e configurações externas utilizadas pela aplicação.

## Arquivos

- `prisma.ts` - Configuração e instância do cliente Prisma para conexão com banco de dados

## Responsabilidade

- Configurar bibliotecas externas
- Fornecer instâncias configuradas para uso na aplicação
- Centralizar configurações de dependências externas
- Gerenciar conexões e configurações de banco de dados
