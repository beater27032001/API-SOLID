# Pasta `utils/`

## Objetivo

Esta pasta contém funções utilitárias reutilizáveis que não pertencem a nenhuma camada específica da aplicação.

## Arquivos

- `get-distance-between-coordinates.ts` - Função para calcular distância entre coordenadas geográficas

## Responsabilidade

- Fornecer funções auxiliares reutilizáveis
- Implementar cálculos matemáticos e algoritmos utilitários
- Manter funções puras e testáveis
- Evitar duplicação de código em diferentes partes da aplicação

## Características

- Funções devem ser stateless (sem estado)
- Fácil de testar de forma isolada
- Reutilizáveis em diferentes contextos
- Sem dependências de frameworks ou bibliotecas específicas
